# Format the completed subagent report

The assignment has already ended. Submit its report through `submit_report` using the required schema. This step only formats the existing response and recorded evidence. Do not repeat the assignment or perform more work.

Preserve the meaning of the response. A readiness acknowledgement is only an acknowledgement. Use empty arrays for work, findings, changes and checks that did not happen. Never invent evidence or a successful review. If a review was not performed, use a failing verdict and explain the missing evidence. Keep uncertainties and blockers explicit.

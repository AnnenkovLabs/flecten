Manage durable project memory. `topics` pages through the directory; `list` filters indexes by exact topic, kind or literal query. `read` uses either `id` or `ids` and returns missing bodies; `sources` exposes eligible evidence. `save` creates a canonical key with `expectedRevision: 0` or updates it with its current revision. `forget` requires the record's id and revision; `reconcile` applies save/forget arrays atomically. Evidence must exactly quote a real user message or non-memory tool result. Preferences and lessons require user evidence.

For terminology, use kind `vocabulary`, key `dictionary/<id>` and structured `dictionary` fields: id, term, aliases, definition, category, optional clarification and HTTPS sources.

# Кодекс поведения

Участники обсуждают код и решения по делу и уважительно. Разные мнения полезны, если они подкреплены фактами.

Недопустимы оскорбления, травля, угрозы, сексуализированное внимание и публикация личных данных без согласия. Техническая критика относится к работе, а не к человеку.

О нарушении сообщи владельцу репозитория приватно. Владелец может предупредить участника, удалить комментарий или закрыть доступ. Обращения рассматриваются без публичного обсуждения.

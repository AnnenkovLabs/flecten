# Trailer workflow

Read the pacing resource when planning a trailer. Establish the intended audience, duration and available footage from the task. Use the timeline tool to check shot timings, frame counts and total duration before proposing an edit. The Trailer timeline workspace lets the user inspect and adjust the same calculation.

This example calculates a timeline. For a finished video, use installed editing or encoding tools and inspect the rendered output. Do not report a rendered trailer from a timeline calculation.

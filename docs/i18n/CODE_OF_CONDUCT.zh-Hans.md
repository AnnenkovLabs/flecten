# 行为准则

## 我们的承诺

我们希望 Flecten 成为一个人们可以自由构建和学习、彼此尊重和理解的地方。参与对所有人开放，不论背景、身份或经验。

## 标准

- 基于事实，就代码和决策本身进行讨论。
- 批评工作，而非个人。
- 假定善意；保持耐心和清晰，尤其对新人。
- 尊重不同的语言、背景和观点。
- 给予并保留对他人工作的署名。

## 不可接受的行为

不容忍侮辱、骚扰、欺凌、威胁、性化关注、歧视，以及未经同意发布个人数据。

## 执行

请私下向仓库所有者报告违规行为。所有者可以警告参与者、删除内容或限制访问。报告会在不公开讨论的情况下处理。

## 适用范围

本准则适用于项目空间，以及在公开场合代表项目时。它补充 [ETHICS.md](../../ETHICS.md) 中的伦理规范；软件本身受 [AGPL-3.0](../../LICENSE) 约束。

## Підтримувані версії

Підтримується лише гілка `main`.

## Як повідомити

Не відкривай публічний issue для вразливості. Використай приватний security advisory GitHub або напиши власнику репозиторію. Вкажи версію, кроки відтворення та можливу шкоду.

Відповідь очікуй протягом 7 днів. Виправлення та розкриття деталей узгоджуються з автором звіту.

## Що перевіряти насамперед

- обхід шляху в протоколі `liquid://`;
- міст `preload` і доступ до `ipcRenderer`;
- `contextIsolation`, `sandbox` і `nodeIntegration` у вікні;
- CSP і завантаження зовнішніх ресурсів;
- вирізання токенів з логів і `events.jsonl`;
- команди `bash` і запис файлів поза дозволеним набором;
- запуск MCP серверів і hooks з `flecten.config.json`;
- передача оточення дочірнім MCP процесам;
- впровадження інструкцій через `SKILL.md` і відповіді MCP.

Архітектурні межі безпеки описані в [docs/SECURITY.md](../../docs/SECURITY.md).

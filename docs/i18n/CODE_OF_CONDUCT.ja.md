## 私たちの誓い

Flecten を、人々が自由に構築し学べ、互いに尊重と理解をもって接する場所にしたいと考えています。参加は、背景・アイデンティティ・経験を問わず、すべての人に開かれています。

## 基準

- コードと決定は事実に基づき、内容について議論してください。
- 人ではなく仕事を批評してください。
- 善意を前提とし、特に新規参加者には忍耐強く明確に接してください。
- 異なる言語・文脈・視点を尊重してください。
- 他者の仕事にクレジットを与え、保持してください。

## 許容されない行動

侮辱、ハラスメント、いじめ、脅迫、性的な関心、差別、同意のない個人データの公開は許容されません。

## 執行

違反はリポジトリの所有者に非公開で報告してください。所有者は参加者への警告、コンテンツの削除、アクセス制限を行えます。報告は公開の議論なしに処理されます。

## 適用範囲

この規範はプロジェクトの空間と、公の場でプロジェクトを代表する際に適用されます。[ETHICS.md](../../ETHICS.md) の倫理規範を補完します。ソフトウェア自体は [AGPL-3.0](../../LICENSE) に従います。

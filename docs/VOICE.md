# Голосовой ввод

Микрофон в композере записывает до 90 секунд. Повторное нажатие останавливает запись и вставляет распознанную речь в черновик. Отправка сообщения остаётся за пользователем. Escape или «Отмена» отменяют запись и распознавание.

## Выбор режима

Откройте **Настройки → Общее → Голосовой ввод → Распознавание речи**.

| Режим | Для чего | Обработка |
| --- | --- | --- |
| API провайдера | Готовый сервис с `/audio/transcriptions` | На сервере выбранного провайдера |
| faster-whisper | Более точная диктовка, несколько языков, сложная речь | На CPU (int8) или NVIDIA CUDA (float16) |
| Vosk | Небольшие модели, скромный CPU, заранее известный язык | На CPU |

Whisper предлагает tiny, base, small, medium, large-v3-turbo и large-v3. Начните со small, а для слабого компьютера с tiny/base. Большие модели обычно точнее, но требуют больше оперативной памяти и работают медленнее. Размеры в меню ориентировочные, пакеты движка занимают дополнительное место.

Vosk предлагает небольшие модели: русский 45 МБ, английский 40 МБ, украинский nano 73 МБ. Язык выбирается вместе с моделью; автоматического определения нет. Качество и пунктуация на свободной речи обычно уступают Whisper. На очень слабом устройстве задержка всё равно зависит от CPU.

## Установка локального движка

1. Установите Python 3.9+ с `venv` и `pip`. Укажите `python3` или полный путь к исполняемому файлу. На Windows можно указать `python` или путь к `python.exe`.
2. Выберите движок, модель и CPU/CUDA. Для CUDA нужны NVIDIA, CUDA 12, cuBLAS и cuDNN 9, доступные Python-процессу. На macOS используйте CPU.
3. Нажмите **Установить движок и модель**. Пакет устанавливается в собственное окружение приложения, затем скачивается выбранная модель. Можно отменить установку. Успешно загруженные модели сохраняются; повторная установка использует имеющиеся файлы.
4. Нажмите **Проверить установку**, затем **Сохранить**. Проверка проверяет пакет и файлы модели; CUDA проверяется при самом распознавании.

Сеть нужна для первичной установки, добавления другой модели и повторной установки пакета. Во время диктовки аудио остаётся на компьютере. Ошибка локального движка показывается пользователю; приложение не переключается на API.

Если Python не найден, укажите полный путь. Если отсутствуют `venv` или `pip`, установите их средствами своей ОС. Если pip не находит подходящий пакет для вашей платформы или версии Python, попробуйте Python 3.12/3.13. При ошибке CUDA установите совместимые библиотеки по инструкции faster-whisper или выберите CPU. На текущем Linux проверены оба движка на CPU; CUDA, macOS и Windows требуют проверки на устройстве.

## Файлы и удаление

Окружения и модели общие для проектов:

- Linux: `$XDG_CACHE_HOME/flecten/voice` или `~/.cache/flecten/voice`.
- macOS: `~/Library/Caches/flecten/voice`.
- Windows: `%LOCALAPPDATA%/flecten/voice`.

В `runtimes/<engine>` лежит venv, в `models/<engine>/<model>` лежит модель. После закрытия приложения можно удалить нужную модель или весь каталог voice. Аудиозаписей там нет. `FLECTEN_VOICE_HOME` задаёт другой корень для тестирования. Если загрузка Vosk была прервана на этапе финального переноса и каталог модели неполон, удалите только этот неполный каталог перед повторной установкой.

## Проверка настоящих движков

Обычные тесты не скачивают Python-пакеты или модели. При готовом cache с Whisper tiny и Vosk small English можно выполнить проверку через настоящий сервис и sidecar handlers:

```bash
FLECTEN_VOICE_HOME=/path/to/voice-cache \
FLECTEN_VOICE_SMOKE_AUDIO=/path/to/mono-16khz-pcm16.wav \
bun test tests/integration/local-voice.test.ts
```

Тот же набор переменных включает дополнительный Electron-тест `tests/e2e/local-voice.spec.ts`. Для него используйте [публичный WAV из Vosk](https://github.com/alphacep/vosk-api/blob/master/python/example/test.wav), потому что проверяется известная английская фраза. Тест подставляет этот файл вместо микрофона, конвертирует запись браузером и вставляет результат настоящего Vosk в редактор.

Исходники и лицензии: [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [Vosk](https://github.com/alphacep/vosk-api), [модели Vosk](https://alphacephei.com/vosk/models), [модели Whisper](https://huggingface.co/Systran).
